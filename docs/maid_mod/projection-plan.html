同一份地形，按玩家问的事翻译

前两步已经有了共享的局部地形，和「看见过才算知道」的认知层。这一步不再增加扫描， 只把同一份地形按问题投影成不同的空间关系：闲聊只给关系句，问路才给图， 找矿给成团清单，失败给现场。模组算几何，插件挑投影并措辞，模型拿到的不是坐标清单。

一、现在缺的不是事实，是关系

回头看一眼的工具已经有出处（眼前 / 刚才），但回给模型的仍是一串扁平事实。

现在回给模型的正前方近处是铁矿石。 眼前这一片能挖的有：铁矿石（minecraft:iron_ore）、石头（minecraft:stone）、煤矿石（minecraft:coal_ore）。 刚才在附近见过：铁矿石（minecraft:iron_ore）。
模型真正需要的正前方三步、同一层是铁矿石，中间隔着两块石头；绕过去大概七步。 左前方四格的铁矿团一共六块，最近的一块隔着两块石头。
有事实、有出处，但没有方位、层高、挡路和步数；同一个矿脉被拆成一串重复 id。插件拿不到相对坐标， 算不出「怎么过去」——这一步要换的是数据的形状，不是继续加清单。

二、谁算、谁写

不新增世界扫描，不动宿主；只在现有的回帧里加「算好的关系」，插件负责挑和说。

模组 · 算几何
相对偏移、方位、层高
挡路块数、局部步数、相连团、失败现场。读共享地形与认知视图，只算不下结论。
插件 · 选投影
这一轮问的是什么
闲聊、问路、找东西、失败各挑一种；翻成中文，控制长度；旧字段缺了就退回现在的说法。
模型 · 用关系
直接说、直接挖
关系句拿来回话；成团清单直接当挖掘目标；失败现场用来改计划，而不是原样重试。
模组：世界语义与几何 插件：选择与措辞 模型：只读结果
↓同一份地形，三种用法
输入
LocalTerrain + 认知视图
事实给动作，认知给台词；这一步不再读第二遍世界。
↓模组算出可直接用的原语
投影原语
relation / cluster / scene / map
关系、相连团、失败现场、按需小图；都是算好的结果，不是原始坐标。
↓插件按问题选一种，翻成中文
输出
关系句 / 小图 / 团清单 / 失败现场
长度跟着当前回复档位走；默认不给矩阵。

三、四种投影

STMR 的消融说明网格本身有效，但固定 20×20 每轮都塞并不划算；这里按问题类型和台词预算决定投影到多细。

投影一 · 闲聊 / 主动开口
关系句（默认）
方位 + 同一层 / 上下几层 + 挡路块数 + 局部步数。一句说完，不给矩阵。
正前方三步、同一层是铁矿石，中间隔着两块石头；绕过去大概七步。
投影二 · 「怎么过去 / 带我去」
近细远粗小图
八格内一格一单元，八到二十四格按二到四格合并；只在玩家明确要路线时给。
从她脚下往左前方走，绕过两块石头后直走；水在右边，不用过。
投影三 · 「附近有铁矿吗」
相连成团的清单
同种方块按相连成团；每团给最近一块、块数、方位。不是一串去重 id。
左前方四格的铁矿团一共六块，最近的一块隔着两块石头；右后方还有一小团，两块。
投影四 · 工具失败
失败现场
真正的原因（够不着 / 站不下 / 路上过不去 / 工具不对）+ 目标周围一小片 + 最近同类。
那块铁矿够不着：上方压着石头，周围没有能站的地方；最近同类在右后方六格。

四、协议只加字段，不改旧字段

新模组多给几项，老插件直接忽略；新插件遇到老模组就退回现在的说法。

relations: [
  { id, seen, dx, dy, dz, facing, same_layer, distance,
    blockers, blocker, walk_steps }
]
clusters: [
  { id, cells, truncated, dx, dy, dz, facing, distance,
    blockers, blocker }
]
scene: { dx, dy, dz, facing, blocked_above, stand_room }
                                  // 只在已定到目标的失败里
map:   { radius, text }           // 只有 detail = map 时才带
  • 老字段原样保留。 正前方、方块清单、block_sight 都还在；新字段是增量，不是替换。
  • 步数只在八格内算。 更远只说「要绕过去」，不跑完整寻路；八格内也只是一次有界的小范围估算。
  • 团清单有上限。 按距离和相关性排序，不把整片矿脉铺满上下文。
  • 小图按需生成。 看一眼周围的工具加一个可选的 detail，默认简短；问路才要图。
  • 不碰宿主。 这是模组与插件之间的回帧，不涉及 manifest，顺序可以模组先行。

五、开工顺序

每一步都能单独验；先加字段不改旧输出，再让插件开始读。

模组 · 投影原语关系、相连团、失败现场、按需小图；先只加字段，旧输出不动。
验收：老回执原样，新字段有单测；不新增世界扫描。
插件 · 选择与措辞按问题挑投影；关系句、团清单、失败现场；detail 参数默认简短。
验收：闲聊不带图，问路才给；老模组回退正常。
文档与真机协议表、README、计划补一节；四种问法各跑一次。
验收：三种问法内容对得上，短回复档位没有变长。
